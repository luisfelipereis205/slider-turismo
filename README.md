# 🌎 Slider Turístico

Projeto de um slider interativo desenvolvido com **HTML, CSS e JavaScript**, criado para praticar os fundamentos do desenvolvimento web front-end e explorar animações, posicionamento de elementos e manipulação do DOM.

## 🌐 Acesse o projeto

🔗 **Link do site:** [https://luisfelipereis205.github.io/slider-turismo/]

## 📸 Sobre o projeto

O **Slider Turístico** é um projeto desenvolvido com o objetivo de praticar a criação de interfaces interativas e dinâmicas para a web.

A aplicação apresenta uma sequência de slides que podem ser alternados por meio de botões de navegação. Cada slide possui uma composição visual própria, com imagens, títulos, cores e animações.

O projeto também explora técnicas de posicionamento e sobreposição de elementos, criando uma apresentação visual dinâmica.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação dos slides, títulos, imagens e botões de navegação.
- **CSS3:** estilização dos elementos, posicionamento, sobreposição de imagens, efeitos visuais e animações.
- **JavaScript:** controle da navegação entre os slides, manipulação de classes e interação com os botões.

## 🎯 Conceitos praticados

- Manipulação do DOM (*Document Object Model*).
- Seleção de elementos com `getElementById()` e `querySelectorAll()`.
- Manipulação de classes com `classList.add()` e `classList.remove()`.
- Eventos de clique com `addEventListener()`.
- Controle de slides utilizando variáveis e índices.
- Operador ternário para alternar entre os slides.
- Posicionamento de elementos com CSS (`position`, `transform` e `z-index`).
- Criação de animações com `@keyframes`.
- Uso de variáveis CSS para personalizar os estilos dos slides.

## ⚙️ Funcionalidades

- Navegação entre slides por meio das setas anterior e próximo.
- Alternância entre os slides sem recarregar a página.
- Retorno ao primeiro slide após o último.
- Navegação reversa, do primeiro slide para o último.
- Animações de entrada para títulos e imagens.
- Personalização visual de cada slide.

## 🚀 Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone [https://github.com/luisfelipereis205/slider-turismo.git]
   ```

2. Entre na pasta do projeto:

   ```bash
   cd slider-turistico
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no Visual Studio Code.
